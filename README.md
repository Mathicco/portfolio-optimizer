# 📈 Portfolio Optimizer
Modern Portfolio Theory Implementation with React + Python

## Stack
- Backend: FastAPI + Python
- Frontend: React + Vite
- Data: Yahoo Finance API

## Getting Started
```bash
# Backend
cd backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python app.py

# Frontend
cd frontend
npm install
npm run dev
```
